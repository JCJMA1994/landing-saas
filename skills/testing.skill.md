# Skill: Testing & QA

## Trigger
Antes de merge/bugfix.

## Objective
Prevenir regresiones funcionales y de seguridad.

## Hard constraints
- negative auth tests.
- deterministic fixtures.
- bugfix regression coverage.

## Workflow
Acceptance -> unit -> integration -> RLS -> E2E -> residual risk.

## Definition of Done
CI verde y denial paths cubiertos.
