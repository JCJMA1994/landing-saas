# Skill: Architecture Guardian

## Trigger
Cambios de boundaries/dependencies/topología.

## Objective
Proteger arquitectura multi-tenant.

## Hard constraints
- UI -> App -> Domain.
- Infrastructure implementa contratos.
- Tenant/site/publication/campaign explícitos.

## Workflow
Clasificar contexto, dependencias, ownership, riesgos, migraciones y tests.

## Definition of Done
Sin boundary violations ni ownership ambiguo.
