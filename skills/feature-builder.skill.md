# Skill: End-to-End Feature Builder

## Trigger
Default para cualquier feature.

## Objective
Coordinar arquitectura, datos, seguridad, UX, tests y docs.

## Hard constraints
- Consultar skills especializados.
- Vertical slice completo.
- No sacrificar seguridad por velocidad.

## Workflow
1. Acceptance criteria.
2. Contexto de dominio.
3. Datos/contratos.
4. Threat model.
5. Server use case.
6. UI.
7. RLS/migrations.
8. Tests.
9. A11y/perf.
10. Docs.

## Definition of Done
Feature end-to-end, segura, probada y documentada.
