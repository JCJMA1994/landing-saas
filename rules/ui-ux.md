# UI/UX Rules
- Tokens semánticos, no CSS libre.
- AA contrast objetivo.
- Focus visible, labels, semantic HTML, alt text.
- Responsive 320/390/768/1024/1440.
- Admin muestra dirty/saved/error states.
- Preview de campaña debe permitir fecha simulada.
- Reorder accesible además de drag/drop.
- Decoraciones nunca deben bloquear CTA, contenido o navegación.
