# Template Design System

## Problema que resuelve
Evitar la plantilla genérica `navbar + hero photo + cards + benefits + footer` repetida con otros colores.

## Direcciones visuales
### tech-diagnostic
Inspirado en herramientas de diagnóstico: status chips, métricas, esquemas de componentes, rejilla técnica.

### repair-workshop
Lenguaje de banco de reparación: labels, part numbers, anotaciones, macrofotografía de piezas, composición modular.

### system-monitor
Dashboard/telemetría reinterpretado como marketing: availability indicator, diagnostic lanes, terminal-like microdetails sin sacrificar legibilidad.

### tech-editorial
Tipografía de gran escala, composición asimétrica, fotografía editorial, mucho espacio negativo.

### cyber-performance
Oscuro, high-performance, workstation/gaming, líneas de energía y métricas de rendimiento.

### friendly-tech
Humano, hogares/PYMEs, ilustración/fotografía cercana, bloques suaves y explicación sencilla.

## Template Manifest
Cada template declara `key`, `version`, `supportedSections`, `supportedCampaignSlots`, `tokenConstraints`, `defaultVariants`.

## Regla
Cambiar el color no constituye una variante de template. Una nueva dirección visual debe cambiar composición, jerarquía, ritmo, tratamiento visual y comportamiento de secciones.
